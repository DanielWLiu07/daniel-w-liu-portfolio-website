# danielwliu.com

My personal portfolio site. Each page has its own visual identity - watercolor backgrounds, manga-style intros, 3D carousels - all tied together with custom page transitions.

## 🍎 Pomme — featured project

Autonomous produce-harvesting robot (HT6 hackathon): a rover + robotic arm with live fruit-ripeness classification and a SLAM / 3D-LIDAR control dashboard.

## Pages

**Landing** - Parallax mountains with animated sun, ink splash transitions

**About** - Watercolor reveal animation, sparkle overlays

**Experience** - Anime-style background with floating timeline cards

**Projects** - 3D card carousel with video thumbnails, manga intro sequence

**Resume** - Interactive desk scene with clickable elements

![About Page](/public/projects/projects/portfolio_website/about.webp)

## Stack

- Next.js 15 / React / TypeScript
- Three.js for 3D scenes
- GSAP for animations
- Tailwind CSS
- Blender for 3D assets and video sequences

## Run locally

```bash
npm install
npm run dev
```

## Performance

The site has a quality selector - high quality loads all videos and animations, low quality uses static images for faster load times on slower connections.
